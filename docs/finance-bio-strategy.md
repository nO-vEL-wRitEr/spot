# SPOT — 금융 × 바이오 결합 전략

SPOT의 차별화 방향은 단순한 가계부나 단순한 식품 정보 앱이 아니라,

> **내가 어디에 얼마를 썼는지와, 그 소비가 어떤 음식·영양·성분으로 이어졌는지를 함께 보여주는 소비 행동 분석 서비스**

로 정의할 수 있습니다.

현재 SPOT은 지출, 장소, 시간, 카테고리, 영양정보, 알레르기 정보, 식품 성분 데이터를 가지고 있으므로 이 두 축을 하나의 구매 기록으로 연결하는 방향이 적합합니다.

---

## 안 1. 구매 영양 장부 — Money to Nutrition

### 개념

지출 한 건을 단순한 금액으로 끝내지 않고, 해당 결제가 어떤 식품과 영양 정보로 연결됐는지를 보여줍니다.

예시:

```text
CU 서면점 · 4,500원
└ 제로 탄산음료
   ├ 열량 0 kcal
   ├ 당류 0 g
   ├ 구연산
   └ 감미료 포함
```

월말에는 다음과 같이 집계할 수 있습니다.

```text
이번 달 식음료 지출 128,000원
건강식 관련 지출 42,000원
간식·음료 지출 51,000원
가장 자주 확인된 성분: 구연산 11회
```

### 장점

금융 데이터와 바이오 데이터가 가장 직접적으로 한 레코드 안에서 연결됩니다.

---

## 안 2. 영양 카테고리별 소비 예산

### 개념

기존의 식비/카페/마트 같은 금융 카테고리에 더해, 식품 소비를 영양 성격별로 다시 분류합니다.

예:

```text
균형식
채소·과일
단백질 중심 식사
간식·디저트
음료
분식
외식
```

사용자는 금액 목표를 직접 설정할 수 있습니다.

예:

```text
이번 달 식음료 예산 250,000원
└ 균형식 관련 소비 90,000원
└ 간식·음료 소비 54,000원
└ 기타 식비 106,000원
```

여기서 목표는 체중 감량을 강요하는 것이 아니라 **본인이 정한 소비·식생활 구성을 확인하는 것**입니다.

### 장점

기존 SPOT의 예산 기능을 거의 그대로 활용하면서 바이오 탭과 연결할 수 있습니다.

---

## 안 3. 소비 시간 × 음식 패턴 분석

### 개념

SPOT에 이미 있는 시간대별 소비 분석에 식품 데이터를 결합합니다.

예:

```text
오후 14~17시
결제 12건 · 63,000원

주요 유형
카페 5회
간식 4회
편의점 3회
```

AI 인사이트는 다음처럼 설명할 수 있습니다.

> 이번 달 오후 시간대에 간식·음료 구매가 집중되어 있습니다. 지난달보다 해당 시간대 결제가 5건 증가했습니다.

이 분석은 사용자의 실제 구매 기록을 설명하는 용도로 사용하고, 건강 상태나 질환을 단정하지 않습니다.

### 장점

SPOT의 기존 시간대별 소비 기능이 단순 금융 통계에서 행동 패턴 분석으로 확장됩니다.

---

## 안 4. 소비 지도 × 음식 유형 지도

### 개념

카카오맵 기반 소비 지도에 장소별 소비 성격을 추가합니다.

예:

```text
스타벅스 서면점
방문 8회
총 지출 61,000원
주요 구매 유형: 음료·디저트

샐러드 매장
방문 4회
총 지출 39,000원
주요 구매 유형: 균형식
```

현재 방문 빈도 색상과 함께 음식 유형을 카드나 마커 상세 정보에 표시할 수 있습니다.

장기적으로는

```text
자주 방문하는 식품 소비 장소
카페 4곳
편의점 3곳
식사 매장 6곳
```

처럼 공간 기반 패턴을 제공할 수 있습니다.

### 장점

다른 가계부 앱에서 보기 어려운 **장소 + 금융 + 음식 패턴**이라는 SPOT만의 시각적 기능이 됩니다.

---

## 안 5. 주간 소비·영양 리포트

### 개념

매주 사용자의 금융과 식품 소비 데이터를 하나의 리포트로 묶습니다.

예:

```text
이번 주 SPOT 리포트

총 소비          83,000원
식음료 소비       46,000원
가장 많이 간 장소  CU 서면점
가장 많은 시간대   16~18시
주요 음식 유형     음료·간식
반복 구매          아메리카노 4회
```

추가로

- 지난주 대비 금액 변화
- 자주 구매한 음식 유형
- 자주 확인된 영양성분·첨가물
- 알레르기 주의 식품 기록
- 반복 방문 지점

등을 한 장에 보여줄 수 있습니다.

AI는 이 데이터를 요약해 다음 주에 확인할 포인트를 제시할 수 있습니다.

### 장점

사용자가 매일 기록하지 않더라도 **매주 다시 앱에 들어올 이유**를 만들어 줍니다.

# 가장 추천하는 구조

1차 MVP에서는 아래 세 기능을 우선 연결하는 것이 좋습니다.

```text
지출
 ↓
구매 상품
 ↓
영양·성분 정보
 ↓
시간 / 장소 / 금액 분석
 ↓
주간 AI 리포트
```

즉, 1번 `구매 영양 장부`를 데이터 구조의 중심으로 두고,
3번 `시간대 패턴`, 4번 `장소 패턴`, 5번 `주간 리포트`를 그 위에 올리는 구조입니다.

---

# 이 방향이 타당한 근거 3가지

## 근거 1. 현재 SPOT의 기존 기능을 버리지 않고 연결할 수 있음

SPOT에는 이미 다음 데이터가 존재합니다.

- 금액
- 카테고리
- 시간
- 장소
- 영수증 OCR
- 소비 통계
- AI 인사이트
- 음식 추천
- 영양정보
- 알레르기 정보
- 첨가물·원재료 정보

따라서 완전히 새로운 서비스를 만드는 것이 아니라, **이미 존재하는 두 데이터 흐름을 `구매 상품`이라는 연결점으로 합치는 작업**에 가깝습니다.

## 근거 2. 일반 가계부와 차별화하기 쉬움

일반적인 가계부는

```text
어디서 / 얼마를 썼는가
```

를 중심으로 분석합니다.

SPOT은 여기에

```text
무엇을 샀는가
그 상품은 어떤 음식 유형인가
어떤 영양·성분 정보가 있는가
언제·어디서 반복 구매했는가
```

까지 연결할 수 있습니다.

즉 경쟁 포인트를 단순한 지출 기록이 아니라 **소비 행동의 의미를 해석하는 것**으로 옮길 수 있습니다.

## 근거 3. AI가 분석할 수 있는 데이터가 훨씬 풍부해짐

금액만 가지고 AI가 할 수 있는 분석은 제한적입니다.

하지만

```text
금액 + 시간 + 장소 + 음식 유형 + 영양정보 + 반복 구매
```

가 함께 있으면 AI가

- 반복 소비
- 시간대 패턴
- 장소 패턴
- 식품 유형별 지출
- 지난주 대비 변화

를 설명할 수 있습니다.

이때 AI는 의료적 판단을 내리는 것이 아니라 **사용자가 기록한 소비·식품 데이터를 요약하고 패턴을 보여주는 역할**로 제한하는 것이 적절합니다.

# 데이터 구조 제안

```text
Expense
├─ id
├─ amount
├─ merchant
├─ placeName
├─ date
├─ category
└─ items[]
    ├─ itemName
    ├─ price
    ├─ foodCategory
    ├─ nutrition
    │   ├─ calories
    │   ├─ carbohydrate
    │   ├─ protein
    │   ├─ fat
    │   ├─ sugar
    │   └─ sodium
    ├─ allergens[]
    └─ additives[]
```

이 구조가 자리 잡으면 영수증 OCR, 금융 거래내역, 바이오 분석을 모두 같은 데이터 모델에 연결할 수 있습니다.

---

# 단계별 구현 제안

### Phase 1 — 현재 MVP

직접 입력 + OCR 데이터에 구매 품목을 연결합니다.

### Phase 2 — 금융 파일 가져오기

카드사·은행 CSV 파일을 불러와 날짜, 상호명, 금액을 자동 등록합니다.

### Phase 3 — 거래와 영수증 매칭

금액·시간·상호명이 비슷한 금융 거래와 영수증을 자동으로 연결합니다.

### Phase 4 — 금융 API

실제 서비스 규모가 커지면 오픈뱅킹·마이데이터·제휴 API 등 공식 금융 데이터 연동을 검토합니다.

---

## 제품 한 줄 정의

> **SPOT은 돈을 얼마나 썼는지만 보여주는 가계부가 아니라, 내 돈이 어떤 음식·장소·소비 습관으로 이어졌는지를 보여주는 소비 행동 분석 앱이다.**
