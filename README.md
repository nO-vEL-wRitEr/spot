# SPOT

소비를 기록하고, 통계를 확인하고, AI가 반복 소비 패턴을 분석해주는 개인 소비 관리 웹앱입니다.

SPOT의 핵심 흐름은 다음과 같습니다.

> 지출 입력 → 데이터 저장 → 통계 자동 갱신 → AI 소비 패턴 분석

단순한 가계부를 넘어서 사용자가 어디에, 얼마나, 얼마나 자주 소비하는지를 구조화하고 이해할 수 있도록 만드는 것을 목표로 합니다.

---

## 주요 기능

### P1 — 핵심 기능

- 카테고리별 소비 분석 및 통계
- 주간·월간 소비 비교
- 월 예산 설정 및 예산 대비 지출률 확인
- AI 소비 분석 및 맞춤형 인사이트
- 반복 소비 패턴 탐지
- 자주 이용한 상호·지점 및 고액 지출 분석

### P2 — 사용성 기능

- 지출 직접 입력
- 지출 수정 및 삭제
- OCR 기반 영수증 인식
- 카테고리별 상세 분석
- 지점명과 상호명을 분리한 장소 데이터 관리
- 지도 기반 소비 위치 확인
- 한국어 / 영어 / 일본어 UI 전환

## 현재 구현된 흐름

### 1. 지출 입력

사용자는 직접 지출을 입력하거나 영수증 이미지를 OCR로 인식해 지출 데이터를 등록할 수 있습니다.

저장되는 주요 데이터 예시:

```text
merchant      상호명
placeName     지점명
placeAddress  주소
latitude      위도
longitude     경도
amount        금액
category      카테고리
date          결제 일시
memo          메모
source        manual / ocr / demo
```

### 2. 로컬 데이터 저장

SPOT은 브라우저의 IndexedDB를 사용합니다.

현재 주요 저장소:

```text
spot-db
├─ expenses
└─ settings
```

기존 localStorage 데이터가 있는 경우 첫 실행 시 IndexedDB로 자동 이전됩니다.

브라우저 새로고침이나 재접속만으로는 데이터가 사라지지 않지만, 사이트 데이터 삭제·시크릿 모드·다른 기기에서는 동일 데이터가 유지되지 않을 수 있습니다.

### 3. 소비 통계

등록된 지출 데이터를 기반으로 다음 정보를 자동 계산합니다.

- 일간 / 주간 / 월간 / 연간 지출
- 카테고리별 비중
- 총 지출
- 결제 건수
- 평균 결제액
- 이전 기간 대비 증감률
- 가장 많이 사용한 카테고리
- 주간 및 월간 비교

카테고리를 클릭하면 해당 기간의 상세 지출 목록과 카테고리별 분석을 확인할 수 있습니다.

### 4. 예산 관리

월 예산을 설정하고 다음 정보를 실시간으로 확인할 수 있습니다.

- 현재 월 지출
- 예산 사용률
- 남은 예산
- 예산 대비 진행률

예산 설정값 역시 IndexedDB에 저장됩니다.

### 5. AI 소비 인사이트

실제 저장된 지출 데이터를 집계해 Gemini API에 전달합니다.

AI 분석 데이터에는 다음 항목이 포함될 수 있습니다.

- 월간 / 주간 지출 변화
- 상위 카테고리
- 자주 방문한 상호
- 반복 지출 패턴
- 고액 지출
- 평균 결제액
- 예산 사용률

AI는 사용자의 실제 지출 데이터 범위 안에서 소비 패턴을 설명하도록 설계되어 있습니다.

### 6. 소비 지도

카카오맵 JavaScript API를 이용해 소비 지점을 지도에 표시할 수 있습니다.

지점명을 별도 데이터로 관리하며, 장소 검색 결과에서 주소·위도·경도를 저장합니다.

지도에서는 다음 기능을 제공합니다.

- 지도 이동
- 확대 / 축소
- 지점 검색
- 소비 지점 마커 표시
- 지점별 결제 횟수 및 총 지출 확인

### 7. 다국어 UI

현재 다음 언어를 지원합니다.

- 한국어
- English
- 日本語

원형 언어 토글을 통해 언어를 변경할 수 있으며 선택한 언어는 IndexedDB에 저장됩니다.

사용자가 직접 입력한 상호명이나 메모는 자동 번역하지 않고 앱 UI 중심으로 번역합니다.

## 환경변수

Vercel에서 아래 환경변수를 설정할 수 있습니다.

```text
GEMINI_API_KEY
KAKAO_MAP_JS_KEY
```

### GEMINI_API_KEY

AI 소비 분석과 AI 채팅에서 사용합니다.

API 키는 공개 JavaScript나 GitHub 저장소에 직접 넣지 않고 Vercel 환경변수로 관리합니다.

### KAKAO_MAP_JS_KEY

카카오맵 JavaScript SDK에서 사용합니다.

카카오 개발자 콘솔에서 실제 배포 도메인을 JavaScript SDK 도메인으로 등록해야 합니다.

## 실행 방법

프로젝트를 로컬에서 실행하려면 정적 서버를 사용하는 것을 권장합니다.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000
```

일부 기능은 외부 CDN, Vercel API Routes, 카카오맵 API 또는 Gemini API가 필요하기 때문에 단순히 `index.html` 파일을 직접 열었을 때는 완전히 동작하지 않을 수 있습니다.

## 데이터 처리 방식

현재 SPOT은 별도의 중앙 사용자 DB 없이 브라우저 내부 IndexedDB를 사용합니다.

장점:

- 서버 DB 없이 사용 가능
- 빠른 MVP 개발
- 네트워크가 없어도 저장 데이터 접근 가능
- 별도 계정 시스템이 없어도 동작

현재 한계:

- 다른 기기와 데이터 동기화 불가
- 브라우저 데이터 삭제 시 데이터가 사라질 수 있음
- 로그인 기반 사용자 분리가 없음

향후 필요할 경우 서버 DB 또는 금융 데이터 연동을 추가할 수 있습니다.

- 사용자 계정 및 기기 간 동기화

- 소비 장소 기반 패턴 분석

## 프로젝트 방향

SPOT은 단순히 지출 금액을 기록하는 것보다,

> 사용자의 소비 데이터를 구조화하고 반복되는 행동 패턴을 이해할 수 있게 만드는 것

을 핵심 가치로 두고 있습니다.

현재는 MVP 단계이며 기능과 데이터 구조를 빠르게 실험하고 개선하고 있습니다.
